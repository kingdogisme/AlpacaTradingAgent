# Alpha Discovery Boundary

Alpha Discovery owns upstream candidate discovery, scoring, confirmation, and
handoff metadata. It feeds research requests; it does not own portfolio
approval or execution.

## Rules

- Discovery output should be candidate/watchlist data.
- Full ATA analysis should be invoked through research/decision services.
- Do not submit orders from discovery flows.
- Keep candidate IDs linked to run IDs and plan IDs for auditability.
